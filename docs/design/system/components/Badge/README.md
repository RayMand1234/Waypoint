Badges are short status labels on cards. The sunshine "Best value" badge is the app's signature signal.

Markup: `<span class="wp-badge wp-badge--value">`. Variants: `--value` (sunshine-400 + ink), `--savings`, `--warning`, `--danger`, `--neutral`.

- Only one `--value` badge per list, on the top best-value option.
- Text is `overline` (uppercase, 11px). Keep it to 1–3 words.
- Status badges always say what they mean in words; color is never the only signal.
